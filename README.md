Through this course, I gained an understanding of:

- Internet of Things (IoT)
- Connected devices
- Smart technologies
- Sensors and connected systems
- Data generated by IoT devices
- Digital transformation
- Role of data in modern organizations
- Artificial Intelligence
- Data Analytics
- Cybersecurity in connected environments
- Emerging technologies
