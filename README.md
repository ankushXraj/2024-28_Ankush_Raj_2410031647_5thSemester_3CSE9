# 1. 🌐 Networking Basics

### About the Course

The **Networking Basics** course introduced the fundamental concepts required to understand how computer networks communicate and operate.

Cisco's course covers networking foundations, network devices, communication media, protocols, IP addressing, basic device configuration, LANs, and application-layer services.

### 📖 What I Learned

Through this course, I developed an understanding of:

- Fundamentals of computer networking
- How data travels through a network
- Different types of network devices
- Routers, switches, access points and endpoint devices
- Network media and communication methods
- Ethernet communication
- IP addressing and its role in network communication
- Basic LAN concepts
- Network protocols
- Application-layer services
- Basic network configuration
- Fundamentals of network troubleshooting
- Basic network security concepts

### 💡 Key Takeaway

This course helped me understand the **foundation of networking**, which is essential for further learning in areas such as cybersecurity, cloud computing, network administration and software development.

# 2. 🔐 Introduction to Cybersecurity

### About the Course

The **Introduction to Cybersecurity** course provided an introduction to the field of cybersecurity and helped me understand the importance of protecting information, systems, networks and users from cyber threats.

### 📖 What I Learned

During this course, I learned about:

- Fundamentals of cybersecurity
- Importance of information security
- Common cybersecurity threats
- Cyber attacks and their impact
- Network security concepts
- Endpoint security
- Data protection
- Vulnerabilities and risks
- Security awareness
- Basic risk management concepts
- Cybersecurity careers and opportunities
- Importance of protecting personal and organizational information

### 💡 Key Takeaway

The course helped me develop a security-oriented mindset and understand that cybersecurity is not only about technology but also involves **people, processes, risk management and responsible digital behavior**.

# 3. 🌐 Introduction to IoT and Digital Transformation

Through this course, I gained knowledge about:

- Internet of Things (IoT)
- Connected devices
- Sensors and smart devices
- Communication between connected devices
- Role of data in IoT
- Digital transformation
- Impact of technology on modern organizations
- Data analytics
- Artificial Intelligence
- Cybersecurity in connected environments
- Smart technologies and connected systems
- Emerging technology trends
- Career opportunities in emerging technologies

### 💡 Key Takeaway

This course helped me understand how **connected devices, data, AI and cybersecurity work together to enable digital transformation**.
